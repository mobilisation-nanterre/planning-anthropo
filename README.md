# Planning des événements du département d'anthropologie

Copie publique, en lecture seule, du planning des événements du département d'anthropologie (Université Paris Nanterre).

Les événements sont saisis dans la page de gestion, réservée aux personnes autorisées. Cette copie est régénérée automatiquement toutes les heures, de 7h à 23h.

- `index.html` : la page publique (générée, ne pas modifier à la main).
- `outils/modele.html` : le modèle de la page.
- `outils/construire.py` : fabrique `index.html` à partir d'un export des salles et des événements.
